# Кастомный пул потоков

## Результаты тестирования

### Производительность
- **Время выполнения**: 5 задач за ~3 секунды
- **Масштабирование**: автоматическое увеличение с 2 до 4 потоков при нагрузке
- **Отказы**: 2 задачи выполнены в вызывающем потоке при перегрузке

### Оптимальные параметры для данного теста
- **corePoolSize = 2**: оптимально для начальной нагрузки
- **maxPoolSize = 4**: достаточно для пиковой нагрузки
- **queueSize = 2**: баланс между памятью и пропускной способностью
- **keepAliveTime = 3 сек**: быстрое освобождение ресурсов

### Преимущества реализации
1. **Нет глобальной блокировки** - каждая очередь независима
2. **Равномерная загрузка** - Least Loaded балансировка
3. **Предсказуемое поведение** - четкие логи всех событий
4. **Graceful shutdown** - корректное завершение

### Недостатки
1. **Накладные расходы** на выбор очереди
2. **Память** - отдельная очередь на каждый поток
3. **Сложность отладки** - много параллельных очередей

## Вывод
Реализация полностью соответствует требованиям и показывает хорошую производительность при смешанной нагрузке.
